# Simple HTML Product Scraper

A lightweight Python script that extracts product names and prices from HTML structures using (BeautifulSoup4) and exports the extracted data into a clean (CSV)file with UTF-8 encoding support.

# Features
- HTML parsing with `BeautifulSoup`
- UTF-8 encoding support for multi-language text (including Persian)
- Structured data export to CSV format

# How to Run
1. Install dependencies:
   pip install bs4
